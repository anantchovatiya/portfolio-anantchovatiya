Resume Placeholder

This is a placeholder for your actual resume PDF file. To add your real resume:

  1. Create your resume as a PDF file
  2. Name it resume.pdf
  3. Place it in the /public directory of your portfolio project

Note: Once you've added your resume.pdf file to the public directory, the "Download Resume" link in your portfolio will automatically point to your actual resume.

In the meantime, this placeholder page will be shown when someone clicks the "Download Resume" link.
